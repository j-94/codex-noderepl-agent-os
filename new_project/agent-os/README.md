# Agent OS Relation

`agent-os` is the runnable packet/route/gate demo. The `new_project` surface is
the workspace entry state that tells a future Codex session how to use that demo
without re-running the history bootstrap.

Relationship:

```text
New project control state
-> Agent OS packet substrate
-> route manifest
-> gate and receipt boundary
```

