# Primitive Atlas v0

Status: local working atlas
Route: TP -> UTIR-style materialization -> receipt
Claim boundary: this is a compact synthesis of local cognitive/control work. It is not production proof, a universal ontology, SWE-bench evidence, or model-weight learning.

## Core Loop

```text
distinguish
-> allocate
-> packetize
-> route
-> gate
-> act or hold
-> receipt
-> promote if repeated
```

The two cognitive roots are:

1. `distinction_creates_pattern`
   - A boundary creates usable structure.
   - This is the source of packets, lanes, gates, types, claim boundaries, and route choices.

2. `resource_constrained_allocation`
   - Scarcity forces selection.
   - This is the source of attention routing, token budgeting, future sampling, patch selection, and bounded work.

## Primitive Discovery Test

Score a candidate primitive with five tests:

1. Auto-generation: does it naturally emerge from the constraints?
2. Necessity: is there a mathematical or operational reason for it?
3. Violation: does ignoring it cause a recognizable failure?
4. Cross-substrate: does it work across chat, code, UI, memory, tools, and runs?
5. Prediction: does it predict better future behavior?

Promotion rule:

```text
passes 5/5 -> primitive candidate
passes in one domain only -> pattern
names a vibe only -> hold
```
